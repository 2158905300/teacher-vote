# 北交威 · 教师情报站

北交大威海校区教师匿名星级评价站（学习项目）。

## 功能
- 271 位教师（13 分类：各专业 + 通识课），数据来自北交大威海校区官网公开师资名录
- 5 维度匿名打分：给分大方 / 教学能力 / 幽默风趣 / 苛刻程度 / 课程收获（1-5 星）
- 综合评分：加权计算（给分25% + 教学30% + 幽默15% + 苛刻反向10% + 收获20%）
- 每人每师一条评分，可修改覆盖（不重复计数）
- 只评分不评论

## 技术
- 纯前端：HTML/CSS/JS（无框架）
- 数据存储：Supabase（Postgres + RLS）
- 部署：GitHub Pages
